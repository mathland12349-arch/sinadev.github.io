# سینا اصغرزاده | وبسایت نمونه‌کار

داده‌های نمونه‌کارها داخل همین ریپوی گیت‌هاب نگه‌داری می‌شوند و نیازی به دیتابیس جدا نیست.

## ساختار
- `index.html` صفحه اصلی
- `data/projects.json` فهرست نمونه‌کارها (دیتابیس سایت)
- `img/` تصاویر، آیکون‌ها و لوگو

## افزودن نمونه‌کار جدید
1. عکس پروژه را در پوشه `img/` بگذار، مثلاً `img/my-shop.jpg` (نسبت حدود ۲ به ۱ بهتر است).
2. یک آیتم به `data/projects.json` اضافه کن:

```json
{
  "title": "فروشگاه آنلاین",
  "kind": "web",
  "image": "img/my-shop.jpg",
  "alt": "توضیح کوتاه تصویر",
  "baked": false,
  "link": "https://example.com"
}
```

- `kind` مقدار `app` یا `web` است.
- `baked: false` یعنی عنوان روی تصویر نوشته شود. اگر عنوان داخل خود عکس هست `true` بگذار.
- `link` اختیاری است. اگر خالی باشد کارت لینک نمی‌شود.
- ترتیب کارت‌ها همان ترتیب فایل است.

3. تغییرات را commit و push کن. با GitHub Pages سایت خودکار به‌روز می‌شود.

## انتشار با GitHub Pages
در ریپو به Settings، بعد Pages برو، منبع را روی شاخه `main` و پوشه `/ (root)` بگذار.

## اگر سایت جای دیگری میزبانی می‌شود
در `index.html` مقدار `DATA_URL` را به آدرس raw فایل در گیت‌هاب تغییر بده:
`https://raw.githubusercontent.com/OWNER/REPO/main/data/projects.json`
